Create a professional, modern, high-performance web application called **“Color Poster Design Generator”** using only **HTML5, CSS3, and vanilla JavaScript**. The website must be fully compatible with **GitHub Pages** and must work without any backend, server, database, build tool, Node.js, React, Vue, Angular, or external framework. ## 1. Main Purpose Build a powerful browser-based poster/background design generator that allows users to create **10,000+ unique poster-style designs** using carefully selected **solid colors and gradient color combinations**. The generated designs must look professional, modern, commercially usable, visually balanced, and suitable for: * Posters * Flyers * Social media backgrounds * Presentation backgrounds * Advertising creatives * Promotional graphics * Web banners * Abstract backgrounds * Vector-style design inspiration The website should feel like a professional design tool rather than a simple random color generator. --- ## 2. Most Important Design Requirement Every generated design must follow a **strict professional color-palette system**. Do NOT generate random color combinations. Do NOT combine unrelated colors simply because they are technically valid. Every design must use carefully curated and harmonious color palettes based on recognized professional color theory and internationally accepted design principles. The system should use color relationships such as: * Complementary * Analogous * Monochromatic * Triadic * Split-complementary * Tetradic * Warm palettes * Cool palettes * Neutral palettes * Pastel palettes * Earth-tone palettes * Luxury palettes * Corporate palettes * Modern editorial palettes * Minimal palettes * High-contrast palettes * Deep/dark palettes * Soft/light palettes The color combinations must always look intentional and professionally designed. --- ## 3. International Color Palette System Create a large built-in color library containing thousands of carefully selected colors. The palette database should include professionally curated colors inspired by internationally recognized color systems and design standards, such as: * Modern web design palettes * UI/UX design palettes * Material-style color relationships * Professional branding palettes * Editorial design palettes * Accessible contrast principles * Traditional color harmony rules * Contemporary graphic design color trends Do not simply generate random RGB values. Each color should belong to a meaningful color family. Color families may include: * Red * Orange * Yellow * Gold * Green * Emerald * Teal * Cyan * Blue * Navy * Purple * Violet * Magenta * Pink * Brown * Beige * Cream * Gray * Charcoal * Black * White The generator must intelligently select colors that work together. --- ## 4. Solid Color Designs Include a dedicated **Solid Color Design Mode**. This mode should generate poster designs using one or multiple solid colors. Examples of design structures: * One-color minimalist composition * Two-color split composition * Three-color geometric composition * Color block composition * Vertical color sections * Horizontal color sections * Diagonal color sections * Corner blocks * Layered blocks * Minimal abstract shapes * Geometric poster layouts * Modern editorial compositions The shapes should be created using normal HTML/CSS elements such as: * div * pseudo-elements * CSS borders * CSS border-radius * CSS transforms * CSS clip-path where appropriate Do not use SVG filters or SVG visual effects. --- ## 5. Gradient Design Mode Include a separate **Gradient Design Mode**. The gradient generator should support: * Linear gradients * Radial gradients * Multiple-stop gradients * Two-color gradients * Three-color gradients * Four-color gradients * Diagonal gradients * Vertical gradients * Horizontal gradients * Center-focused gradients * Corner-focused gradients * Soft gradients * Deep gradients * Luxury gradients * Pastel gradients * Neon-inspired but controlled gradients The gradients must always be based on a harmonious professional palette. Avoid ugly rainbow-style random gradients unless the user explicitly selects a rainbow option. Gradient colors should be selected intelligently from compatible palette groups. --- ## 6. Design Categories / Styles Create many different professional poster composition styles. The system should include at least the following style categories: 1. Minimalist Poster 2. Modern Geometric 3. Editorial 4. Corporate 5. Luxury 6. Abstract 7. Swiss-Inspired 8. Contemporary 9. Futuristic 10. Retro 11. Soft Modern 12. Bold Graphic 13. Minimal Gradient 14. Color Blocking 15. Creative Agency Style Each category should produce a different visual structure. The designs must not simply change colors. The actual composition/layout should also change. --- ## 7. 10,000+ Unique Design Requirement The application must be capable of producing **at least 10,000 unique design combinations**. Uniqueness should come from a combination of: * Layout * Shape arrangement * Shape size * Shape position * Rotation * Scale * Number of elements * Color palette * Color placement * Gradient direction * Gradient position * Border radius * Spacing * Alignment * Composition type * Background treatment Do not simply generate a random number and claim there are 10,000 designs. The underlying design system must actually have enough variation to generate thousands of meaningful designs. --- ## 8. Professional Color Rules Implement strict rules to prevent bad color combinations. For example: * Do not use more than a controlled number of dominant colors. * Use one primary color with one or two supporting colors where appropriate. * Use neutral colors when needed to create visual balance. * Maintain sufficient contrast. * Avoid visually conflicting combinations unless intentionally selected as a design style. * Avoid excessive saturation. * Avoid random fluorescent combinations. * Avoid muddy color combinations. * Avoid unnecessary color noise. * Avoid using every color family in one design. Every generated design should look as though a professional graphic designer selected the colors. --- ## 9. Color Palette Browser Add a dedicated **Color Palette Library** panel. Generate Button Create a large, visually prominent **“GENERATE DESIGN”** button. When clicked: * Generate a completely new design. * Change the composition. * Change the color palette according to the selected rules. * Maintain professional visual harmony. * Do not repeat the immediately previous design. Randomize Button Include a **“Randomize”** button. Randomization must not mean completely uncontrolled randomness. Users should be able to: * Favorite designs * Unfavorite designs * View all favorites * Clear favorites Store favorites using **localStorage** so they remain after refreshing the page. --- ## 14.
